# 🎂 Age Calculator

A simple and responsive Age Calculator built using HTML, CSS, and JavaScript.

This project allows users to calculate their age in years, months, and days by entering their date of birth.

## 🚀 Live Demo

https://bashrat365.github.io/age-calculator/

## ✨ Features

- Calculate age from date of birth
- Shows age in years, months, and days
- Prevents future dates
- Simple and clean user interface
- Responsive design
- Works on desktop, tablet, and mobile devices
- Instant calculation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📖 How It Works

The user selects their date of birth from the date picker.

JavaScript compares the selected date with the current date and calculates the difference in:

- Years
- Months
- Days

The calculated age is then displayed on the screen.

## 📱 Responsive Design

The Age Calculator is designed to work smoothly on:

- Desktop
- Laptop
- Tablet
- Mobile
